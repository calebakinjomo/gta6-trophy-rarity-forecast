Forecasts, for every Grand Theft Auto VI trophy on PlayStation 5, the percent of players Exophase tracks who will have earned it one week after launch, as five quantiles per trophy. It reads the house's recorded reads of Exophase's trophy page and fits each trophy's curve in log-time, expecting a refresh-driven dilution while the page is frozen and damped curve growth once it starts moving.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
